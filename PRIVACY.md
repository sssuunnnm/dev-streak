# DevStreak Privacy Policy

Last updated: August 25, 2026

DevStreak is a local-first iOS app designed to help users maintain a daily GitHub activity habit.

## Data We Do Not Collect

DevStreak does not collect, store, sell, or share your personal data on our servers.

We do not collect:

- Daily activity records
- Idea notes
- Reminder settings
- GitHub personal access tokens
- Clipboard contents
- Analytics or tracking data

## Data Stored On Your Device

DevStreak stores app data locally on your device, including:

- Daily activity records
- Idea notes and tags
- Reminder preferences
- Widget snapshot data

This data is stored using Apple-provided local storage technologies such as SwiftData, UserDefaults, App Groups, and Keychain.

## GitHub Integration

DevStreak may connect to GitHub to check whether the configured public repository has recent content changes.

GitHub verification is read-only. DevStreak does not create commits, branches, pull requests, issues, or any other GitHub content.

If you choose to enter a GitHub personal access token, it is stored only in the iOS Keychain on your device and is used only to authenticate read-only GitHub API requests.

DevStreak does not send your GitHub token to our servers.

## Claude Hand-Off

DevStreak can generate a writing prompt from your saved idea and copy it to the clipboard.

DevStreak does not call the Claude API and does not send your idea content to Anthropic or to our servers automatically. If you choose to open Claude and paste the prompt, your use of Claude is governed by Claude's own terms and privacy policy.

## Notifications and Widgets

DevStreak uses local notifications to remind you to write. Notification preferences are stored on your device.

DevStreak widgets read only a minimal local snapshot shared between the app and widget through App Groups.

## Third-Party Services

DevStreak does not use analytics SDKs, advertising SDKs, or tracking SDKs.

The app may make read-only requests to GitHub's public API. Your use of GitHub is governed by GitHub's own terms and privacy policy.

## Data Deletion

You can delete your app data by deleting records inside the app where supported, removing your GitHub token from settings, or deleting the app from your device.

Deleting the app removes locally stored app data according to iOS behavior.
